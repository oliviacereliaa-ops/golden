# Kawan Lama Manufacturing — Factory Explorer

## Run
Open index.html in a modern browser, or serve this folder with any static web server.
The presentation quiz answer is 630. This client-side quiz is a presentation gate, not secure authentication.

## GitHub Pages
Upload the contents of this folder into the root of your golden repository. index.html must be at the repository root, not inside another folder. Keep assets/, history.css, history.js and .nojekyll alongside it.
In repository Settings > Pages, choose Deploy from a branch, main, /(root). Wait for the Pages deployment to succeed.

## 2025 & Before
- Starts with the historical factory overview. C is left, B middle, A right; D/E leave the middle approach open.
- Show more opens 2022, 2023, 2024, 2025 and Growth.
- Workers walk and miniature sewing-machine needles move. Rotate/zoom remains available in the overview.
- Product images reveal in sequence, lift on hover and tilt slightly with the pointer. They are image layers, not fully rotatable 3D product meshes.
- Growth uses rising dimensional typography and four chronological steps (not value-scaled chart heights).
- Revenue in Rp billion: 2022 190.0; 2023 294.2; 2024 392.3; 2025 423.0.
- YoY shown for 2023 +54.9%, 2024 +33.3%, 2025 +7.8%.
- Profit shown only for 2024 21% and 2025 25%, exactly as supplied.
- Arrow keys navigate, Escape returns to the factory. Pause motion and reduced-motion support included.

Now and 2027 Plan remain available. Only Now opens segment panels.

## Editing
history.js contains capability content and growth values. history.css controls the presentation styling. index.html contains the factory model, timeline and existing segment panels. All assets use relative paths and no external runtime dependencies.
